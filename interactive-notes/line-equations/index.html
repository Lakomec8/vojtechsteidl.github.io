01 / Princip

Všechno stojí na bodu a vektoru.

Parametrická rovnice

Víme, kterým bodem přímka prochází a kterým směrem vede. Parametr t určuje polohu bodu na přímce.

x = x₀ + ut
y = y₀ + vt
t ∈ ℝ, (u,v) ≠ (0,0)
Obecná rovnice

Každý bod (x,y) na přímce musí splnit jednu rovnost. Vektor n = (a,b) je k přímce kolmý.

ax + by + c = 0
(a,b) ≠ (0,0)
Nejdůležitější rozlišení: směrový vektor u = (u,v) leží podél přímky; normálový vektor n = (a,b) je na přímku kolmý. Platí au + bv = 0.
Směrový vektor

u = (u,v). Při změně t o 1 se bod posune právě o tento vektor.

Normálový vektor

n = (−v,u) nebo (v,−u). Obě možnosti popisují tutéž přímku.

Jedna přímka, více rovnic

Směrový i normálový vektor lze násobit nenulovým číslem.

02 / Interaktivní laboratoř

Posuň bod a otoč směrový vektor.

Změň souřadnice počátečního bodu A, směrový vektor u a parametr t. V grafu sleduj oranžový bod P(t), modrý směrový vektor a čárkovanou normálu.

Přímka prochází bodem A a má směrový vektor u

Značení v grafu: A = zadaný bod, P = bod určený parametrem t. Při u = v = 0 přímka není určena.

Kontrola při převodu: do obecné rovnice dosaď známý bod A. Levá strana musí vyjít 0. Když vyjde něco jiného, je nejčastěji chyba ve znaménku konstanty c.
03 / Převod mezi zápisy

Parametrická → obecná a zpět.

Parametrická → obecná

Máme bod A = (x₀,y₀) a směrový vektor u = (u,v). Zvolíme normálu n = (−v,u).

−vx + uy + (vx₀ − uy₀) = 0

Příklad: A = (1,2), u = (3,4).

1. n = (−4,3).
2. −4x + 3y + c = 0.
3. −4·1 + 3·2 + c = 0 → c = −2.
Výsledek: −4x + 3y − 2 = 0.

Obecná → parametrická

Pro rovnici ax + by + c = 0 už máme normálu n = (a,b). Směrový vektor zvolíme u = (b,−a) a najdeme jeden bod A dosazením.

x = x₀ + bt
y = y₀ − at

Příklad: 2x − y + 3 = 0.

1. n = (2,−1), tedy u = (−1,−2).
2. Pro x = 0 vyjde y = 3; bod A = (0,3).
Výsledek: x = −t, y = 3 − 2t.
Převodník: z obecné rovnice na parametrickou

Zadej koeficienty do rovnice ax + by + c = 0. Převodník najde bod A a směrový vektor (b,−a).

04 / Přímka dvěma body

Dva různé body určují jedinou přímku.

Máme-li A = (x₁,y₁) a B = (x₂,y₂), směrový vektor získáme odečtením u = B − A = (x₂ − x₁,y₂ − y₁). Bod A dosadíme do parametrických rovnic a z nich získáme obecnou.

Spočítej směrový vektor a obě rovnice ze dvou bodů
Zvláštní případy: svislá přímka má tvar x = k (v obecné rovnici je b = 0); vodorovná má tvar y = k (a = 0). Obecná rovnice funguje pro obě, na rozdíl od směrnicového tvaru y = kx + q.
05 / Ověření a vzájemná poloha

Jak poznáš, jestli bod leží na přímce?

Pro obecnou rovnici jen dosadíš souřadnice do ax + by + c. Nula znamená, že bod na přímce leží. U parametrického vyjádření musí stejné t vyjít z obou rovnic.

Dosazení bodu do obecné rovnice
Rovnoběžné přímky

Normálové vektory jsou násobky. Dvě přímky mohou být rovnoběžné různé, nebo splývat.

Kolmé přímky

Normálové vektory mají nulový skalární součin: a₁a₂ + b₁b₂ = 0.

06 / Typové příklady

Jak postupovat u písemky.

1. Sestav parametrické rovnice z bodu a vektoru.

A = (−3,2), u = (4,−1).

Ukázat postup a kontrolu
x = −3 + 4t, y = 2 − t, t ∈ ℝ.
Pro t = 0 získáme A. Pro t = 1 získáme B = (1,1), takže vektor AB = (4,−1).
2. Přepiš parametrické rovnice na obecnou.

x = 2 + 3t, y = −1 − 2t.

Ukázat postup a kontrolu
u = (3,−2), n = (2,3), proto 2x + 3y + c = 0.
Dosazení A = (2,−1): 4 − 3 + c = 0 → c = −1.
Výsledek: 2x + 3y − 1 = 0.
3. Přepiš obecnou na parametrickou.

3x + 2y − 6 = 0.

Ukázat postup a kontrolu
n = (3,2), u = (2,−3).
x = 0 → 2y − 6 = 0 → A = (0,3).
Výsledek: x = 2t, y = 3 − 3t, t ∈ ℝ.
4. Rozhodni, zda bod patří přímce.

p: x = 1 + 2t, y = 3 − t. Patří P = (5,1) na p?

Ukázat postup
Z x: 5 = 1 + 2t → t = 2. Z y: 1 = 3 − t → t = 2.
Stejné t v obou rovnicích → ano.
5. Průsečík dvou přímek.

p: x + y − 5 = 0, q: x − y − 1 = 0.

Ukázat postup
Sečteme rovnice: 2x − 6 = 0 → x = 3.
Dosadíme do x + y − 5 = 0 → y = 2.
Průsečík: P = (3,2).
Typická chyba: směrový vektor (u,v) není normálový! Když z něj stavíš obecnou rovnici, musíš ho otočit o 90°, např. na (−v,u).
