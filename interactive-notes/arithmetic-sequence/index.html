01 / Definice

Všechno stojí na konstantním rozdílu

Aritmetická posloupnost je řada čísel, ve které se mezi sousedními členy přičítá stále stejná hodnota. Této hodnotě říkáme diference a značíme ji d.

a₁2a₂5a₃8a₄11a₅14
an+1 = an + d    /   rekurentní zadání

Od prvního členu k n-tému uděláme jen n − 1 kroků. Z toho plyne vzorec pro libovolný člen.

an = a1 + (n − 1) · d
Monotónnost: pokud d > 0, posloupnost roste; pro d < 0 klesá; pro d = 0 je konstantní.
02 / Grafická laboratoř

Co dělá první člen a co diference?

Pohybuj posuvníky. Body v grafu představují dvojice (n, an). Propojení bodů je jen vizuální pomůcka — indexy posloupnosti jsou diskrétní.

04 / Výpočet ze dvou členů

Co když neznáme a₁ ani d?

Ze dvou různých členů sestavíme dvě rovnice. Jejich odečtením získáme diferenci přímo.

d = (am − ak) / (m − k)

Příklad níže je interaktivní. Měň indexy i hodnoty a sleduj, jak se změní obecný předpis a dvacátý člen.

Znalost a₁ není nutná: an = ak + (n − k)d.
05 / Součty

Sečti n členů pomocí párování

První + poslední člen dávají stejný součet jako druhý + předposlední. Počet párů při sudém n je n/2. Obecný vzorec platí i pro liché n.

Sn = n(a1 + an)/2
Sn = n[2a1 + (n−1)d]/2

06 / Řešené příklady

Čtyři typové postupy, které musíš zvládnout

1. Urči a₂₀ pro a₁ = 7 a d = 4
Z předpisu: a₂₀ = 7 + (20−1)·4 = 7 + 76 = 83. Častá chyba je dosadit 20 místo 19.
2. Je dáno a₄ = 11 a a₁₀ = 35. Urči a₁.
d = (35−11)/(10−4) = 4. Z 11 = a₁ + 3·4 získáme a₁ = −1.
3. Sečti prvních 30 členů posloupnosti 3, 7, 11, …
Je dáno a₁ = 3, d = 4. Proto a₃₀ = 3 + 29·4 = 119. Součet: S₃₀ = 30·(3+119)/2 = 1830.
4. Když a₁ = 5, d = 3 a Sₙ = 670, urči n.
670 = n[10+3(n−1)]/2, tedy 3n² + 7n − 1340 = 0. Kořeny jsou 20 a −67/3; index musí být přirozený, takže n = 20.
Tři sousední členy se vyplatí zapisovat jako x−d, x, x+d. Jejich prostřední hodnota je aritmetickým průměrem krajních: 2x=(x−d)+(x+d).
