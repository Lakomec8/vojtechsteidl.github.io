Parametrické nerovnice bez hádání

Parametr je pevné číslo, které zatím neznáme. Neřešíme ho spolu s neznámou — zkoumáme, kdy mění postup, pořadí bodů nebo počet řešení.

3× kontrola

Před dělením zjisti znaménko. Před intervalem seřaď kritické body. Před odevzdáním zkontroluj definiční obor a ostré/neostré konce.

Algoritmus, který drží řešení pohromadě

Kritická hodnota parametru je místo, kde se může změnit matematický příběh.

1

Role písmen

Urči, co je neznámá a co parametr. Výsledkem je množina neznámé podle parametru.

2

Podmínky

Jmenovatel ≠ 0, odmocnina ≥ 0. Podmínku napiš dřív, než začneš upravovat.

3

Zlomové hodnoty

Nula koeficientu, D = 0, splynutí kořenů nebo změna jejich pořadí.

4

Případy a kontrola

Vyřeš každý případ, zapiš intervaly a ověř reprezentantem i krajním bodem.

Čtyři živé laboratoře

Posuvník mění parametr. Graf i číselná osa se přepočítají okamžitě.

Parametr ve jmenovateli

(x − 3)/(x + a) ≥ 1

x ≠ −a   a   (−3−a)/(x+a) ≥ 0

a < −3: čitatel je kladný ⇒ x+a > 0 ⇒ K = (−a, ∞)

a = −3: zlomek je 0, ale jmenovatel nesmí být 0 ⇒ K = ℝ ∖ {3}

a > −3: čitatel je záporný ⇒ x+a < 0 ⇒ K = (−∞, −a)

Proč nelze křížem násobit hned?

Protože neznáme znaménko x+a. Při záporném jmenovateli by se nerovnost obrátila a při nulovém není výraz definován. Převod na jeden zlomek je bezpečný.

Prázdný bod je zakázaná hodnota x = −a. Zelená část osy je řešení.

Po částech

|y| + y ≥ r

|y|+y = 0 pro y<0;   |y|+y = 2y pro y≥0

r ≤ 0: pro záporná y je 0≥r a pro nezáporná 2y≥0≥r ⇒ K = ℝ.

r > 0: záporná y nevyhoví; pro y≥0 dostáváme y≥r/2 ⇒ K=[r/2,∞).

Hraniční bod y = 0

Patří do větve y≥0. Pro r=0 platí rovnost, takže řešením jsou opravdu všechna reálná čísla.

Modře je graf f(y)=|y|+y, oranžově hladina r, zeleně řešení.

Absolutní hodnota jako vzdálenost

|y + 5| < r

vzdálenost y od −5 je menší než r

r ≤ 0: nezáporná vzdálenost nemůže být menší než nekladné číslo ⇒ K=∅.

r > 0: −r<y+5<r ⇒ K=(−5−r,−5+r).

Co změní znak ≤?

Pro r>0 budou konce uzavřené. Pro r=0 vznikne jediné řešení y=−5. Pro r<0 zůstává prázdná množina.

Otevřené konce připomínají, že nerovnost je ostrá.

Diskriminant a vrchol

x² + 4x − g ≥ 0

(x+2)² − (g+4) ≥ 0;   D=4(g+4)

g ≤ −4: minimum je −g−4 ≥ 0 ⇒ K=ℝ.

g > −4: kořeny −2±√(g+4), parabola je nezáporná vně ⇒ K=(−∞,x₁]∪[x₂,∞).

Proč je při g = −4 řešením celé ℝ?

Výraz je (x+2)²≥0. V bodě −2 je roven nule a neostrá nerovnost rovnost dovoluje.

Zelené úseky značí, kde je parabola na ose nebo nad ní.

Součin a pořadí kořenů

x² + qx < 0

x(x+q)<0;   nulové body 0 a −q

q < 0: 0<−q ⇒ K=(0,−q).

q = 0: x²<0 ⇒ K=∅.

q > 0: −q<0 ⇒ K=(−q,0).

Obecný součin z ručního zápisu

U u(u−1)(u−s)²≥0 bod u=s má sudou násobnost: znaménko se v něm nemění. Přesto může patřit do řešení díky „≥“. Pořadí 0, 1, s se musí rozdělit podle s<0, s∈[0,1] a s>1, včetně shodných bodů s=0,1.

Parabola otevřená nahoru je záporná pouze mezi dvěma různými kořeny.

Nejčastější pasti

Dělení parametrem

V ax>6 nelze napsat jen x>6/a. Pro a<0 se znak obrací, pro a=0 se do původní nerovnice dosazuje.

Odmocnina z q²

√(q²)=|q|, nikoli obecně q. Jinak můžeš pro q<0 prohodit nebo ztratit kořeny.

Bod bez kontroly

Nula čitatele může patřit, nula jmenovatele nikdy. Otevřenost konce určuje znak </>, uzavřenost ≤/≥.
