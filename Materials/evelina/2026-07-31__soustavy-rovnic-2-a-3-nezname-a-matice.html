Soustavy lineárních rovnic

Nejprve soustavy se dvěma neznámými, potom se třemi neznámými a nakonec stejný postup zapsaný pomocí matice.

1. Soustavy rovnic se dvěma neznámými

Soustava dvou rovnic se dvěma neznámými obsahuje dvě rovnice, které musí platit současně. Hledáme dvojici čísel x a y, která vyhovuje oběma rovnicím.

Hlavní myšlenka: jednu neznámou odstraníme. Nejčastěji rovnice vhodně sečteme nebo odečteme.

Jak postupovat

  1. Vyber neznámou, kterou chceš odstranit.
  2. Uprav rovnice tak, aby u této neznámé byly stejné nebo opačné koeficienty.
  3. Rovnice sečti nebo odečti.
  4. Vypočítej zbývající neznámou.
  5. Výsledek dosaď do jedné původní rovnice a dopočítej druhou neznámou.
  6. Proveď kontrolu v obou původních rovnicích.
Při násobení rovnice násobíš celý řádek: všechny členy vlevo i číslo na pravé straně.

Vzorový příklad

(1) 2x + y = 7 (2) 3x − 2y = 4

Chceme odstranit y. V první rovnici je koeficient 1, ve druhé −2. První rovnici proto vynásobíme dvěma.

2·R₁
(1') 4x + 2y = 14 (2) 3x − 2y = 4

Teď rovnice sečteme. Členy +2y a −2y se vyruší.

R₁' + R₂
4x + 2y = 14 + 3x − 2y = 4 ---------------- 7x = 18

x = 18/7

Dosadíme do první původní rovnice:

2·18/7 + y = 7 y = 7 − 36/7 y = 13/7
Řešení: x = 18/7, y = 13/7.

Příklady k procvičení

  1. x + y = 9;   2x − y = 3
  2. 3x + 2y = 16;   x − 2y = 0
  3. 2x + 3y = 1;   4x − y = 11
  4. 5x − 2y = 4;   3x + 2y = 12
Výsledky

1) x = 4, y = 5   2) x = 4, y = 2   3) x = 17/7, y = −9/7   4) x = 2, y = 3

2. Soustavy rovnic se třemi neznámými

U tří rovnic se třemi neznámými hledáme trojici x, y, z. Postup je stejný jako u dvou neznámých, jen eliminaci provedeme ve více krocích.

Cíl: ze tří rovnic vytvořit dvě rovnice pouze se dvěma neznámými. Ty potom vyřešíme stejně jako předchozí soustavu.

Jak postupovat

  1. Vyber jednu neznámou, například x.
  2. Odstraň x z druhé rovnice pomocí první rovnice.
  3. Odstraň x také ze třetí rovnice.
  4. Vznikne soustava dvou rovnic se dvěma neznámými.
  5. Vyřeš ji eliminační metodou.
  6. Zpětným dosazením dopočítej poslední neznámou.

Vzorový příklad

(1) x + y + z = 6 (2) 2x − y + z = 3 (3) x + 2y − z = 2

Krok 1: odstraníme x z druhé rovnice

R₂ ← R₂ − 2R₁
(2x − y + z) − 2(x + y + z) = 3 − 12 −3y − z = −9

Krok 2: odstraníme x ze třetí rovnice

R₃ ← R₃ − R₁
(x + 2y − z) − (x + y + z) = 2 − 6 y − 2z = −4

Nyní máme soustavu dvou rovnic se dvěma neznámými:

(A) −3y − z = −9 (B) y − 2z = −4

Krok 3: odstraníme y

Rovnici B vynásobíme třemi a sečteme s rovnicí A.

3B: 3y − 6z = −12 A: −3y − z = −9 ------------------ −7z = −21

z = 3

Dosadíme do B:

y − 2·3 = −4 y = 2

Nakonec dosadíme y a z do první původní rovnice:

x + 2 + 3 = 6 x = 1
Řešení: x = 1, y = 2, z = 3.

Příklady k procvičení

  1. x + y + z = 6;   2x − y + z = 3;   x + 2y − z = 2
  2. x + y + z = 3;   2x − y + z = 2;   x + 2y − z = 2
  3. x + 2y − z = 3;   2x − y + z = 2;   3x + y + 2z = 4
Výsledky

1) x = 1, y = 2, z = 3   2) x = 1, y = 1, z = 1   3) x = 1, y = 1, z = 0

3. Řešení pomocí matice

Matice je jen zkrácený zápis stejného postupu. Místo celých rovnic zapisujeme pouze jejich koeficienty a pravé strany.

x + y + z = 6 2x − y + z = 3 x + 2y − z = 2

Rozšířená matice:

⎡ 1 1 1 │ 6 ⎤ ⎢ 2 −1 1 │ 3 ⎥ ⎣ 1 2 −1 │ 2 ⎦

Povolené řádkové operace

Prohození řádků
R₁ ↔ R₂
Násobení řádku číslem
R₂ ← 3R₂
Přičtení násobku jiného řádku
R₂ ← R₂ + 2R₁
Odečtení násobku jiného řádku
R₃ ← R₃ − R₁

Postup

R₂ ← R₂ − 2R₁,   R₃ ← R₃ − R₁
⎡ 1 1 1 │ 6 ⎤ ⎢ 0 −3 −1 │ −9 ⎥ ⎣ 0 1 −2 │ −4 ⎦
R₂ ↔ R₃
⎡ 1 1 1 │ 6 ⎤ ⎢ 0 1 −2 │ −4 ⎥ ⎣ 0 −3 −1 │ −9 ⎦
R₃ ← R₃ + 3R₂
⎡ 1 1 1 │ 6 ⎤ ⎢ 0 1 −2 │ −4 ⎥ ⎣ 0 0 −7 │ −21 ⎦

Z posledního řádku dostaneme z = 3. Z druhého řádku y = 2 a z prvního řádku x = 1.

Důležité: Operace R₃ ← R₃ + 3R₂ znamená, že nový třetí řádek počítáme sloupec po sloupci.
